This mod restores Oblivion and its associated text in KH1FM Reverse/Rebirth, and does absolutely nothing else. Because of the nature of how text modification in KH1 works, this mod has to include the entire changed file, which means it **cannot be used to restore Oblivion in other mods that change it**. That's such a highly specific use case, though, so this is probably a non-issue.

**Because this mod has to include the full file, it will conflict with any other mod that changes the same text files.** (This is, again, probably a non-issue, but still worth mentioning.)

Original mod by GuidingHeart.
